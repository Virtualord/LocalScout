## [0.1.0] - 2026-10-13

### Added

- Local-first lead research: discover local businesses, audit their websites with
  measured facts, and draft grounded outreach for a human to review and send.
- SerpApi Google Maps discovery with a disk cache and a recorded-fixtures mode.
- Deterministic website audit: SSRF-guarded fetch, HTML checks, Lighthouse
  performance, and a table-driven findings catalog with an opportunity score.
- Drafting over an open-weight model (Gemma via Ollama or any OpenAI-compatible
  endpoint) with a numeric grounding validator and deterministic fallback
  templates in English, Hinglish, and Hindi.
- Mastra workflow, local HTTP API with SSE progress, and a SQLite/Drizzle store.
- React web app with a token-driven design system and an accessible pixel map.
